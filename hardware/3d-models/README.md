
# 3D Models — Smart Refrigerator

This directory contains the 3D models developed for the ESP32-based Smart Refrigerator prototype.

## 1. Refrigerator Body

**File:** [refrigerator-body.stl](./refrigerator-body.stl)

The main enclosure of the refrigerator.

| Parameter | Value |
|---|---:|
| Width | 200 mm |
| Depth | 150 mm |
| Height | 150 mm |

## 2. Refrigerator Door

**File:** [refrigerator-door.stl](./refrigerator-door.stl)

The separately modeled refrigerator door, designed to fit the main enclosure.

| Parameter | Value |
|---|---:|
| Width | 196 mm |
| Depth | 21 mm |
| Height | 130 mm |

## 3. Fully Assembled Model

**File:** [refrigerator-fully-assembled.stl](./refrigerator-fully-assembled.stl)

The combined 3D model containing the refrigerator body and door in their assembled positions.

The overall mesh bounding dimensions are approximately:

- 200 mm
- 170.5 mm
- 150 mm

These dimensions represent the assembled model's bounding box, not the internal storage capacity.

## 4. Design and Manufacturing

The models were prepared for 3D printing and evaluated in slicing software.

The provided STL files represent the geometric design of the refrigerator enclosure and its door.

## 5. Notes

- Dimensions are based on the exported STL geometry.
- The assembled model is provided for visualization and reference.
- The body and door are also available as separate models.
- The STL files do not include the electronic components or internal cooling hardware.
